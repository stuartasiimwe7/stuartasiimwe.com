ESP32 room-condition logger

A first build in sensor acquisition, I²C debugging and measurement. The goal is a reproducible temperature-and-humidity record with honest fault reporting.

Specification: 6 October 2026No hardware measurements yet

Wiring and acquisition

With USB disconnected, join the Feather QT connector to the sensor QT connector. Black is ground, red is the switched 3.3 V supply, blue is SDA and yellow is SCL. Leave the sensor at address 0x44. Keep it separated from controller heat.

The Arduino scaffold enables QT power, scans I²C, and emits a CSV sample every five seconds. Missing or invalid readings remain empty with an error status. A Python serial collector adds host UTC timestamps.

Build specification and firmware source include purchasing alternatives, setup instructions and the evidence format.

Test milestones

  1. Measure the sensor supply; target 3.3 V ±5%.
  2. Confirm address 0x44 and an explicit missing-sensor state.
  3. Capture ten minutes of five-second samples; inspect invalid reads and gaps.
  4. Compare ten paired readings with a documented reference after settling.
  5. Test absent-sensor boot and resets. Disconnect I²C only with power off.
  6. Capture 24 hours; report actual duration, valid fraction, resets and largest gap.

These are acceptance targets. Every milestone remains pending.
